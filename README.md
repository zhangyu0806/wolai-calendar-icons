# Wolai 日历图标

2024-2034 年全部日期的 Wolai 风格日历图标（SVG 格式，红色主题）。

## 使用方式

通过 GitHub raw 链接直接引用：

```
https://raw.githubusercontent.com/zhangyu0806/wolai-calendar-icons/main/{年份}/{月-日}.svg
```

示例：

```
https://raw.githubusercontent.com/zhangyu0806/wolai-calendar-icons/main/2024/06-15.svg
https://raw.githubusercontent.com/zhangyu0806/wolai-calendar-icons/main/2025/01-01.svg
```

## 在 Notion 中使用

直接将上述链接粘贴为图片 URL 即可显示日历图标。

## 目录结构

```
├── 2024/
│   ├── 01-01.svg
│   ├── 01-02.svg
│   └── ... (全年 366 天)
├── 2025/
│   └── ...
├── ...
└── 2034/
    └── ...
```

## 图标来源

图标由 [wolai](https://www.wolai.com) 日历图标 API 生成。
